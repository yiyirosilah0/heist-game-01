Midnight Museum Heist — a stealth heist game in one museum room at night. Slip past three patrolling guards and two sweeping wall cameras, each with a visible vision cone, steal the glowing diamond, and escape through the exit while the alarm meter fills whenever an eye is on you and drains when you break line of sight. Title screen, pause, clean-getaway win and caught lose screens, restart, and deterministic screenshot scenes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, or click where to go. Grab the diamond, then reach the EXIT.
